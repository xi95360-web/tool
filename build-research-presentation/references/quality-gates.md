# Quality Gates

Use these as pass/hold gates. Do not call the deck final while a critical item is on hold.

## Gate 1 — Assignment Fit

- [ ] Route, audience, duration, venue, language, and format are known
- [ ] Required questions and institutional constraints are covered
- [ ] The deck is scoped to fit the time with Q&A protected
- [ ] Assumptions are explicit
- [ ] Confidentiality, permissions, and ethics/governance constraints are recorded where relevant

## Gate 2 — Scientific Spine

- [ ] One-sentence thesis or central question is precise
- [ ] The gap follows from cited evidence
- [ ] Section order is causal, inferential, chronological, or otherwise explicit
- [ ] Transitions explain why the next slide follows
- [ ] The closing answers the opening question
- [ ] No circular reasoning or missing premise

## Gate 3 — Evidence

- [ ] Every factual claim has a source or is labeled user-provided
- [ ] Every proposed result is labeled as a prediction
- [ ] Every scientific claim has a Claim ID and controlled evidence status
- [ ] Primary sources support specific claims
- [ ] Figure, page, table, panel, or data locator is recorded
- [ ] Causal language matches the design
- [ ] Negative, null, and conflicting evidence is represented fairly
- [ ] No invented metadata, data, statistics, controls, or mechanisms
- [ ] Essential sources meet the required full-text/caption/method/supplement read level
- [ ] Inaccessible decisive evidence remains marked `EVIDENCE_GAP`

## Gate 4 — Proposal Rigor

Apply only to proposals:

- [ ] Central hypothesis is falsifiable
- [ ] Each aim tests a distinct part of the hypothesis
- [ ] Controls, outcomes, analysis, and success criteria are explicit
- [ ] Dependencies and fallback paths are visible
- [ ] Feasibility is supported by resources, prior work, or preliminary data
- [ ] Risks have triggers and concrete alternatives
- [ ] Milestones map to decisions, not just activities

## Gate 5 — Journal Club Rigor

Apply only to journal clubs:

- [ ] Authors' claims are separated from the presenter's verdict
- [ ] Authors' claims and all necessary main/supplemental evidence are mapped, including exclusion rationales
- [ ] Every included main figure is explained as question–design–result–interpretation
- [ ] Controls, sample size, uncertainty, and statistics are addressed
- [ ] Alternative explanations are discussed
- [ ] At least one independent or boundary-setting source is included
- [ ] Limitations are ranked by consequence
- [ ] The final verdict uses calibrated confidence

## Gate 6 — Slide Contract

For each content slide:

- [ ] Claim/question title
- [ ] One scientific purpose
- [ ] Readable evidence object
- [ ] Key observation visibly annotated
- [ ] Bounded interpretation
- [ ] Limitation or uncertainty where relevant
- [ ] On-slide source locator
- [ ] Claim IDs and statuses match the claim ledger
- [ ] One-sentence take-home
- [ ] Logical transition

No evidence-bearing slide may pass on visual appeal alone.

## Gate 7 — Figure Integrity

- [ ] Values, axes, groups, and meaning match the source
- [ ] Cropping does not remove interpretive context
- [ ] Adaptation is labeled
- [ ] Quantitative adaptations have a transformation log and side-by-side value check
- [ ] Fonts, lines, legends, structures, and scale bars are readable
- [ ] Sample size, error bars, tests, controls, and units are explained
- [ ] Images/spectra have acquisition and selection context
- [ ] Conceptual art is labeled and cannot be mistaken for data

## Gate 8 — Citation Integrity

- [ ] All identifiers resolve
- [ ] Metadata are accurate
- [ ] Retractions/corrections and peer-review status are checked when relevant
- [ ] Citation is adjacent to the supported material
- [ ] Full references are available in backup or an accompanying file
- [ ] No citation is used merely for prestige
- [ ] Search log documents scope, exact queries, dates, filters, exclusions, and limitations

## Gate 9 — Rendered Visual QA

- [ ] Every slide was rendered and inspected
- [ ] Rendered-image count equals slide count
- [ ] No clipping, overflow, overlap, or broken glyphs
- [ ] No stretched, pixelated, or unreadable figures
- [ ] Titles, body text, axes, and legends are readable at distance
- [ ] Contrast and color distinctions are accessible
- [ ] Alignment, margins, object sizes, arrows, and typography are consistent
- [ ] Whitespace is balanced and purposeful
- [ ] The audience always knows where to look
- [ ] Artifact-open test, font/overflow findings, and reviewer observations are recorded

## Gate 10 — Delivery

- [ ] Speaker notes contain key reasoning and caveats
- [ ] Timing has been rehearsed or realistically estimated
- [ ] Conclusions are protected from time cuts
- [ ] Likely expert objections have concise answers
- [ ] Backup slides cover methods, controls, risks, and extra evidence
- [ ] PPTX and PDF open correctly
- [ ] Speaker notes survived export/serialization where notes were requested
